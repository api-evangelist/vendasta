# Vendasta

> Vendasta is an end-to-end commerce and operating platform that lets agencies, media companies, banks, telcos and other channel partners sell digital products and services to small and medium-sized businesses under their own brand. Its public Marketplace API V1 is a REST API secured with OAuth2 bearer tokens for managing accounts, users, customers, add-ons, activities, executive reports and file groups.

This llms.txt was generated by API Evangelist from the Vendasta catalog profile and repository artifacts (no provider-published /llms.txt was found on developers.vendasta.com as of 2026-07-21).

## APIs

- [Vendasta Marketplace API V1](https://developers.vendasta.com/api/v1): REST API for accounts, users, customers, marketplace apps, activities, executive reports and file groups (OAuth2 bearer).
